Project Name: Campus Lost and Found Portal

Brief Description:
The Campus Lost and Found Portal is a full-stack academic web application built using the MERN stack (MongoDB, Express.js, React.js with Vite, and Node.js) styled with Tailwind CSS. It provides a centralized, authenticated platform for college students and faculty to report, search, and recover misplaced personal and academic belongings across the campus.

Key features include:
- Secure JWT-based User Authentication & Authorization (Student / Faculty / Staff)
- Real-time search by keyword, item type (Lost / Found), status (Open / Returned), and category filters
- Device photo upload using Multer with automated storage and preview
- Personal User Dashboard for tracking reported items and marking them as Returned upon resolution
- RESTful API following MVC architecture with MongoDB & Mongoose schemas
